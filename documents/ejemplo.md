# Documento de ejemplo

Este es un documento de prueba para el NotebookLM offline.

## Sobre el proyecto

El proyecto permite hacer preguntas en lenguaje natural sobre tus propios
documentos (texto, Markdown y PDF) sin conexión a internet, usando un modelo
de lenguaje pequeño (SLM) acelerado con OpenVINO en un Intel N100.

## Dato de prueba

La capital de este proyecto de ejemplo es la ciudad ficticia de "Vinotopía",
fundada en el año 2026.

Puedes borrar este archivo y poner los tuyos en la carpeta `documents/`.
